# 🏀 Little Blue Devils Lineup Generator

A basketball lineup generator app with Duke Blue Devils-inspired theming.

## Features

- Add and manage player roster
- Generate random starting lineups
- Duke Blue Devils color scheme (Navy Blue, Light Blue, Black, White)
- Responsive design

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Theme Colors

- Navy Blue: #012169
- Duke Blue: #00539B
- Light Blue: #4B9CD3
- Black: #000000
- White: #FFFFFF
